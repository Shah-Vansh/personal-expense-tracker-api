
# Personal Expense Tracker API

A RESTful backend API built using Python, Flask, and PostgreSQL to manage daily expenses.

## Tech Stack

- Python
- Flask
- PostgreSQL (planned)
- Flask-SQLAlchemy (planned)
- Postman

## Features

- Add expenses
- View all expenses
- Update expenses
- Delete expenses
- Filter expenses by category and date
- Calculate monthly expense totals
- Pagination

## Project Status

Phase 1: Flask application initialized.

## Local Setup

1. Create a virtual environment:

   python -m venv venv

2. Activate the environment on Windows CMD:

   venv\Scripts\activate

3. Install dependencies:

   python -m pip install -r requirements.txt

4. Run the Flask application:

   python app.py

The API runs at http://127.0.0.1:5000/
